业务闭环说明
闭环1：AI功能使用闭环
用户点击AI按钮 → 系统查询应用控制管理 → 判断租户购买状态 → 未购买：跳转服务购买页 → 购买后权限生效 → 可使用AI功能 已购买：进入AI功能页 → 使用AI生成 → 扣减额度 → 记录使用日志 → 额度不足提示续费
闭环2：直播稿业务闭环
选择直播场次 → 自动读取主播/商品信息 → AI生成直播稿 → 预览 → 不满意：对话式优化 → 重新生成 → 预览 确认：生成访问链接 → 提词器使用
闭环3：通讯录运营闭环
建立组织关系（代理→门店→店员→客户） → 系统生成建群建议 → 运营确认建群 → 群内推送券/商品/活动 → 客户行为采集 → 转化数据回流 → 门店/店员/代理维度统计
