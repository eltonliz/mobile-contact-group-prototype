①  租户线上销售：(购买的SAAS某版本：配置了(供应商、采购、店铺、门店、渠道)的权限菜单）基础班 )

业务文字说明

租户画像：租户愿意备货，且有自己的货源，需要一套私域的在线商城，售卖商品

租户需求：私域卖场

1：租户管理自己的供应商

2：供应商管理货品、组合品，这里没有商品的描述什么的，主要是价格和供应商是否存在【账期 == 月结、季度结、半年结、年度结】

3：租户选择商品、定好采购价(含税、不含税)和数量，供应商要开票，库存接收地址，也就是门店。如果有云仓可以后期接入

4：租户提交采购单，支付采购单，供应商完成采购单履约

5：租户设置好售价、运费、渠道角色佣金(如果购买了渠道应用能力的话)

6：租户购买套餐中含有店铺(菜单那个店铺)，那么就可以在私域流量池中售卖（直播、APP、小程序、货架）都可以上

7：这时候就是B2C现货销售订单，买家支付完成后，根据渠道规则进行梳理结算明细

8：担保保交易完成，确认收货；可以入账各方(租户、供货商、支付渠道、渠道角色(经销商、店长、店员)、平台)

9：各方可以查看待结算明细、结算明细

10：各方允许进行提现

本次闭环内容

1：商品流（供应商->门店->店铺->线上店铺商品列表页面->商品详情页面）

2：订单正正向流 (商品详情页面 -> 提交订单 -> 手动支付假支付 -> 商家处理流程-> 商家完成履约)

3：订单逆向流程（买家会员中心->订单列表或订单详情->发起售后->商家售后处理->售后(仅退款、退货退款)）

本次需求不涵盖，预计会在下周5、6，与直播间、一同评审
